Question 3 of 4

What is the difference between call, apply, and bind?

All three control what this points to inside a function
call
▶ runs now
fn.call(obj, a, b)
args: comma separated
apply
▶ runs now
fn.apply(obj, [a, b])
args: an array
bind
🎁 returns a new function
const g = fn.bind(obj)
runs later: g(a, b)
Call = Comma · Apply = Array

Question 4 of 4 · bonus

The four promise combinators

Promise.all
Waits for every promise to fulfill
Rejects on the first rejection
Promise.allSettled
Waits for every promise to settle
Never rejects: a status for each
Promise.race
Waits for the first to settle
Result: success or failure
⚠ race([]) never settles
Promise.any
Waits for the first to fulfill
Rejects only if all reject: AggregateError
