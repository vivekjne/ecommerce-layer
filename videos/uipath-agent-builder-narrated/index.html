Memory

Learn from past experiences

Context: what is relevant right now
Memory: what happened before
Episodic memory
A past case: inputs, outputs, outcome, feedback
A similar request arrives later
The earlier experience guides the new run
Escalation memory
An uncertain case is escalated
A human resolves it
A similar case later reuses that decision

Guardrails

Safe and responsible agents

Agent calls a tool
Guardrail check
Passes: the tool executes
Fails: block or escalate
Before a tool runs, check:
Is it allowed?
Are the inputs valid?
Is sensitive information involved?
Does it need approval?
Should it be logged or monitored?
Matters most when an agent can:
Update systems
Send messages
Change records
Trigger business processes
