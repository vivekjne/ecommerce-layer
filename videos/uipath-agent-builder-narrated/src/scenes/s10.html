Guardrails

Safe and responsible agents

Agent calls a tool
Guardrail check
Passes: the tool executes
Fails: block or escalate
Before a tool runs, check:
Is it allowed?
Are the inputs valid?
Is sensitive information involved?
Does it need approval?
Should it be logged or monitored?
Matters most when an agent can:
Update systems
Send messages
Change records
Trigger business processes
Autonomy = unlimited access
Autonomy inside clearly defined boundaries
