Three states

Pending, then settled — exactly once

pendingstill waiting…
fulfilledhas a value
rejectedhas a reason
Once settled, a promise never changes state again.
Create & consume

new Promise → .then / .catch

const order = new Promise((resolve, reject) => { setTimeout(() => { if (milk) resolve("latte"); else reject(new Error("no milk")); }, 2000);}); order .then(drink => console.log(drink)) .catch(err => console.log(err.message)) .finally(() => console.log("done"));

Chaining

Each .then returns a new promise

Values flow down the chain. One error skips straight to .catch.

getUser()→ user
.then(getOrders)→ orders
.then(render)→ page
.catch(show)handles any failure
{ id: 7 }
async / await

Same promises, reads top to bottom

async function showOrders() { try { const user = await getUser(); const orders = await getOrders(user); render(orders); } catch (err) { show(err); }}
remember
await pauses this function — not the page. async functions always return a promise. try/catch replaces .catch().
Many promises at once

Promise combinators

Promise.all
waits for all — fails fast on any rejection
→ [a, b, c]
Promise.allSettled
waits for all — reports every outcome
→ [ok, fail, ok]
Promise.race
first to settle wins, success or failure
→ fail (it was fastest)
Promise.any
first to fulfill wins, ignores failures
→ c
